# Latentcolor

Latentcolor is a professional photo editor that runs on your device in your
browser. Ask your agent to adjust exposure, grade color, or make selective
edits to a local photo. The agent opens the photo in Latentcolor, where you
can see each change, adjust it yourself, and export when you are ready.

## Setup

Use an agent session on the same computer as a supported desktop browser.
Install the [Latentcolor CLI](https://github.com/dscruggs/latentcolor-extensions/blob/main/docs/install.md)
or explicitly ask your agent to install it. Verify it with
`latentcolor version --json`.

Try asking, “Open this photo in Latentcolor, lift the shadows, and warm the
highlights slightly. Leave it open so I can fine-tune it.”

The editor processes the photo in your browser. Your agent provider handles
the prompts, file paths, and command output you share with the agent under
its own privacy settings.
